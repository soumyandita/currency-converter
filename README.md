
# 💱 Currency Converter

A modern and responsive currency converter built with **HTML, CSS, and JavaScript**. Convert currencies easily using a free exchange rate API.

## ✨ Features

- 🌍 Supports multiple currencies
- 💱 Converts one currency into another
- 🔄 Easy currency selection
- 📱 Responsive design for mobile and desktop
- ⚡ Fast and user-friendly interface
- 🌐 Fetches exchange rates using an API

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling and responsive layout
- **JavaScript** — Conversion logic and API integration
- **Exchange Rate API** — Currency exchange rate data

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/soumyandita/currency-converter.git
```

### 2. Open the Project

Navigate to the project folder:

```bash
cd currency-converter
```

### 3. Run the Application

Open `index.html` in your browser or use the **Live Server** extension in Visual Studio Code.
